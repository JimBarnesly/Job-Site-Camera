# Job Site Camera

A local-first Android camera for keeping work photos out of your personal gallery.

## v0.1
- Dedicated work camera
- Project-based storage
- Work photos saved in app-private storage
- Work-only gallery
- On-device classification hooks
- Export-ready architecture
- Evidence Mode with configurable project/date/GPS/category/asset/note stamps
- Clean original retained; stamped derivative generated for viewing/export

## Evidence model

Evidence Mode is non-destructive. The original image remains untouched in private project storage. Capture metadata is stored separately, and a stamped JPEG can be generated later for handover, reports, or evidence packs.
